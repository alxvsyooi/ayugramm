# localsearchuf

Монитор онлайна **своих** Telegram-аккаунтов. Один watcher-аккаунт следит за
списком твоих аккаунтов по `@username`/id и пишет, когда кто заходит в онлайн,
а когда кто-то давно не появлялся — помечает как возможно «лёгший».

## Что нужно

- Python 3.10+
- Один «наблюдатель» — Telegram-аккаунт, с которого ведётся слежка.
- `api_id` / `api_hash` с https://my.telegram.org → **API development tools**.

> Важно: watcher видит онлайн цели, только если у цели в приватности
> **«Последняя активность и сетевой статус»** не скрыт от него. Для своих
> аккаунтов это решается: добавь watcher в контакты или выставь приватность так,
> чтобы он видел статус.

## Установка

```bash
pip install -r requirements.txt
cp config.example.ini config.ini      # впиши api_id / api_hash
cp targets.example.txt targets.txt    # впиши свои аккаунты
```

## Запуск

```bash
python monitor.py            # постоянный мониторинг
python monitor.py --once     # один проход и выход (проверить настройку)
```

При первом запуске Telethon попросит номер телефона watcher-аккаунта и код из
Telegram — это одноразово, дальше работает по файлу сессии.

## Как читать вывод

- `🟢 ... ЗАШЁЛ В ОНЛАЙН` — цель появилась в сети.
- `⚪ ... ушёл в офлайн (был ...)` — ушла, с временем последнего онлайна.
- `⚠ ... не был онлайн дольше N мин` — давно тишина, стоит проверить аккаунт.
- `⚠ ... пропал из доступа / недоступна` — цель не находится по id/username
  (возможный бан/слёт).

Всё то же дублируется в файл `monitor.log`.

## Настройки (`config.ini`)

- `poll_interval_sec` — как часто опрашивать (по умолчанию 60 сек).
- `offline_alert_min` — через сколько минут без онлайна считать, что аккаунт лёг.
